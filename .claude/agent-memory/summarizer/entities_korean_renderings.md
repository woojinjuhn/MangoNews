Use these forms consistently across newsletters. Proper-noun acronyms stay in Latin; product codenames stay in original.

## Companies
- AMD → AMD
- NVIDIA / Nvidia → 엔비디아 (in flowing prose) or NVIDIA (in spec contexts). Default: 엔비디아.
- Google / Alphabet → 구글 / 알파벳. "구글 클라우드" for the division.
- Microsoft → 마이크로소프트 (or MS short form once introduced).
- Amazon / AWS → 아마존 / AWS.
- Meta → 메타.
- Qualcomm → 퀄컴.
- TSMC → TSMC.
- Marvell → 마벨.
- Broadcom → 브로드컴.
- Tenstorrent → Tenstorrent (English, no katakana-style).
- Cerebras → Cerebras (English).
- Huawei → 화웨이.
- SMIC → SMIC.
- Korea fabless trio → 리벨리온, 퓨리오사AI (or 퓨리오사), 하이퍼엑셀 (NOT 하이퍼액셀).
- DeepX → 딥엑스 (with English in parens on first use).
- Moreh → Moreh (English; CEO 조강원).
- KSIA → 한국반도체산업협회 (KSIA on second mention).

## Currency unit math (project-wide rule, must be exact)
- $1B = 10억 달러
- $10B = 100억 달러
- $100B = 1,000억 달러
- $1T = 1조 달러
- KRW: 50조원 ≈ $33B (used in K-Nvidia context).

Always cross-check each currency mention against source body. Do not invent units. When source uses raw $, convert to 억 달러 in Korean prose; keep raw $ for unit prices (e.g., $30,926 ASP, $110,000 system price).
