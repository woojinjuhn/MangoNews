Around the end of each calendar quarter's earnings cycle (last week of April, July, October; first week of February), Stage-1 input is heavily weighted toward `market` category — Q1 2026 run had 11/27 in market. Capex announcements, TPU/Trainium strategy, AWS/Azure/Google Cloud growth, and Korean export figures all cluster.

**Why:** This is a real news-cycle effect, not a filtering bias. Hyperscaler earnings drop within a 5-7 day window and reshape the AI-infra demand baseline.

**How to apply:** On these days, accept market-skewed `category_breakdown_main` (e.g., 2-3 market slots is normal; treating it as over-concentration would force less-important stories into main). Use the four-dimension rank (시장 영향력 / 망고부스트 직원 주목도 / 대중 관심도 / 카테고리 분산) — earnings weeks often legitimately tilt the first two heavily toward market while still leaving room for products and competitor-tagged collaboration/projects items.
