2026-05-15 수집물에서 삼성전자 5/21 18일 총파업 관련 기사가 10개(id 5,7,8,9,10,11,12,13,38,43,44,45,46,47)로 몰렸음. 단일 사건의 8개 동일-각도 중복을 모두 keep하면 filter_2가 top-8 만들 때 1개 사건이 절반을 잡아먹음 — 의도적으로 4개 각도로 압축.

**Why:** Stage 1은 generous하게 keep하라는 가이드이지만, "동일 사건의 동일 각도" 중복은 generous의 예외. filter_2는 top-8만 선택하므로 너무 많은 동일 사건 angle을 통과시키면 다른 카테고리(NVIDIA·TSMC·Cerebras 등)가 무조건 밀려남.

**How to apply:** 단일 사건이 ≥5개 기사로 클러스터될 때 다음 각도별 1개씩만 keep하는 휴리스틱:
1. 운영 영향(감산·웜다운·일일 손실액)
2. 경영진/리더십 발신(CEO 발언·우려)
3. 협상 동학(노조 입장·정부 중재·최후통첩)
4. 비즈니스 영향(로드맵·시장 점유율·경쟁사 반사이익) — 다른 각도가 강하면 별도 카테고리(products)로 분리
5. 한국어 1차 정리본 1개(정부 대응 등 영문에 없는 디테일 있을 때) — [[feedback-korean-source-preference]] 참조

같은 각도면 가장 권위 있고/디테일 풍부한 1개만 keep, 나머지는 "duplicate of id X" 사유로 discard.

이번 케이스 keep 분배:
- id 7 (KH emergency mode) — 운영 영향 종합
- id 5 (KH 전영현 발언) — 경영진 위기감
- id 10 (Sedaily 40조 거부) — 협상 결렬 임계점
- id 38 (TechTimes Revives Shelved Chip) — 비즈니스 영향(로드맵 재가동)
- id 47 (한국경제) — 한국어 1차본(정부 긴급조정권 디테일)
- id 8 (Sedaily DRAM 36% 위협) — 메모리 시장 구도 별도 각도, 추가 keep

10개 → 6개 keep. 동일 사건 클러스터 60% 유지율은 통상적 30% 가이드보다 높지만 사건 비중(100조 손실 위협) 감안 정당화.
